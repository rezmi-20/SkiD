# Marketplace Guidelines

> Defines the UX, UI patterns, and interaction standards for hiring, freelance, service, and talent marketplace platforms. The goal is to maximize trust, transparency, and conversion while reducing friction for both buyers and sellers.

---

# Marketplace Philosophy

A marketplace succeeds when users can:

- Discover opportunities quickly
- Compare options confidently
- Build trust easily
- Complete transactions safely
- Return because of a great experience

Every screen should reduce uncertainty.

---

# Core Design Principles

Always prioritize:

1. Trust
2. Transparency
3. Simplicity
4. Speed
5. Credibility

Never hide important information.

---

# User Types

A marketplace typically serves two primary user groups.

## Buyers

Examples:

- Employers
- Clients
- Companies
- Recruiters

Goals:

- Find the right candidate
- Compare options
- Hire quickly
- Stay within budget

---

## Sellers

Examples:

- Freelancers
- Contractors
- Job Seekers
- Agencies

Goals:

- Showcase expertise
- Build credibility
- Receive opportunities
- Get paid securely

Both experiences should receive equal attention.

# Search Experience

Search should be the primary interaction.

Support:

- Instant search
- Keyword search
- Saved searches
- Recent searches
- Autocomplete

Search should remain visible while browsing.

---

# Filters

Filters should help users narrow results quickly.

Common filters:

- Category
- Skills
- Location
- Hourly Rate
- Budget
- Availability
- Experience
- Language
- Rating
- Job Type

Display active filters clearly.

Allow users to remove filters individually.

---

# Sorting

Support common sorting options.

Examples:

- Best Match
- Newest
- Highest Rated
- Lowest Price
- Highest Price
- Most Experienced
- Recently Active

Always indicate the active sort option.

---

# Listing Cards

Each listing should communicate essential information at a glance.

Include:

- Profile photo or company logo
- Name
- Title
- Short description
- Skills
- Experience
- Rating
- Reviews
- Hourly rate or salary
- Availability

Avoid overcrowding cards.

---

# Candidate Profiles

Profiles should answer three questions immediately:

- Can they do the work?
- Can I trust them?
- Can I afford them?

---

## Profile Sections

Include:

- Profile photo
- Headline
- Bio
- Skills
- Portfolio
- Employment history
- Education
- Certifications
- Reviews
- Response rate
- Completion rate
- Availability

Organize information into clear sections.

---

# Company Profiles

Display:

- Logo
- Industry
- Company size
- Description
- Open positions
- Reviews
- Hiring history
- Verification status

Trust indicators should be prominent.

---

# Trust Signals

Trust drives conversions.

Display:

- Verified badges
- Ratings
- Number of reviews
- Response time
- Completion rate
- Repeat client percentage
- Identity verification
- Payment verification

Never fake trust metrics.

---

# Reviews

Reviews should include:

- Reviewer
- Rating
- Date
- Comment
- Project type (optional)

Allow users to sort reviews.

Highlight verified reviews.

---

# Portfolio

Portfolio items should include:

- Cover image
- Title
- Description
- Skills used
- Project duration
- Client feedback (optional)

Support image galleries and external links.

---

# Messaging

Messaging should remain contextual.

Features:

- Attachments
- Image previews
- Typing indicators
- Read receipts (optional)
- Conversation history

Avoid forcing users to leave the hiring workflow.

---

# Job Posting

Posting a job should be simple.

Recommended flow:

1. Title
2. Description
3. Skills
4. Budget
5. Timeline
6. Experience Level
7. Visibility
8. Publish

Show progress throughout the flow.

---

# Applications

Each application should display:

- Applicant
- Proposal
- Budget
- Estimated timeline
- Cover letter
- Portfolio
- Rating

Allow quick comparison.

---

# Payments

Payment information should always be transparent.

Display:

- Budget
- Platform fee
- Taxes (if applicable)
- Milestones
- Escrow status
- Payment schedule

Never hide fees until checkout.

---

# Milestones

Large projects should support milestones.

Each milestone should include:

- Title
- Description
- Amount
- Due date
- Status

Allow milestone approvals.

---

# Notifications

Notify users about:

- New messages
- New applications
- Interview requests
- Contract updates
- Payment updates
- Milestone approvals

Avoid excessive notifications.

---

# Saved Items

Support:

- Saved jobs
- Saved candidates
- Saved searches
- Favorite freelancers

Make saved items easy to access.

---

# Empty States

Examples:

```
No candidates found.

Try adjusting your filters.

[ Clear Filters ]
```

```
No saved jobs yet.

Save interesting opportunities to review later.

[ Browse Jobs ]
```

---

# Dashboard

Marketplace dashboards should display:

For Buyers:

- Open jobs
- Active contracts
- Pending applications
- Recent messages
- Upcoming interviews

For Sellers:

- Active proposals
- Earnings
- Contracts
- Reviews
- Messages
- Recommended jobs

---

# Mobile Experience

On mobile:

- Collapse filters into a drawer
- Prioritize search
- Use bottom sheets where appropriate
- Simplify profile layouts
- Keep actions thumb-friendly

---

# Accessibility

Every marketplace should support:

- Keyboard navigation
- Screen readers
- High contrast
- Semantic HTML
- Clear focus states

---

# Performance

Optimize:

- Infinite scrolling (optional)
- Lazy-loaded images
- Virtualized lists
- Cached search results

Users should never wait unnecessarily.

---

# Marketplace Checklist

Before release, verify:

- Search works correctly
- Filters are intuitive
- Listings are informative
- Profiles build trust
- Reviews are authentic
- Payments are transparent
- Messaging is contextual
- Empty states exist
- Mobile experience is optimized
- Accessibility standards are met

---

# Anti-Patterns

Avoid:

- Hidden pricing
- Fake reviews
- Misleading ratings
- Excessive profile clutter
- Long application forms
- Poor search relevance
- Confusing payment flows

---

# Inspiration

Design experiences comparable to:

- Upwork
- Fiverr
- Toptal
- LinkedIn Jobs
- Wellfound
- Contra
- Arc.dev

Study these products for interaction patterns—not to copy their appearance.

---

# Golden Rule

Trust is the most valuable feature of a marketplace.

Every design decision should make users feel confident about discovering, hiring, collaborating, and completing transactions safely.
